# Engineer Log 🛠️

Приложение для управления инженерными знаниями, ведения дневника наладки ЧПУ, разработки и CI/CD процессов.

## 🏗 Архитектура
- **Backend**: .NET 8 (C#), Entity Framework Core, PostgreSQL
- **Frontend**: React (TypeScript), Vite, Tailwind CSS
- **Deployment**: Docker (изолированные контейнеры)

## 🚀 Ключевые возможности
- 📂 Категоризация записей с цветовой индикацией
- 🏷️ Система тегов для гибкой классификации
- 🔍 Фильтрация и полнотекстовый поиск
- 📥 Экспорт данных в CSV (Excel)
- 🧪 Unit-тесты (TDD) с покрытием бизнес-логики

## 🛠 Локальный запуск
```bash
./deploy.sh
```
Приложение будет доступно по адресу: `http://localhost:8081`
